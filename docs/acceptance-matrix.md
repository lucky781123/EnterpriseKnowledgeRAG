## P2：生产演进方案

必须形成文档并写明触发条件、代价和迁移步骤：

- K8s 多副本、在线/摄取资源池和 GPU 池；
- PostgreSQL、对象存储、索引的备份恢复与 RPO/RTO；
- 多可用区、灾备、密钥管理、审计和合规；
- Embedding/Prompt/模型/索引的影子评测、灰度和回滚；
- 云上迁移（按岗位目标选择 ACK 或 EKS）；
- Incident Response、发布门禁、回滚和复盘。

## 完成状态语义

- `设计中`：只有方案，没有实现或实验。
- `已实现`：代码存在，但未完成验证。
- `已验证`：有可复现测试或实验产物。
- `已冻结`：作为当前版本基线，不轻易改变。
- `已废弃`：保留原因和替代方案。
